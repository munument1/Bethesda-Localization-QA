1. Oblivion **Original** 환경에 **Better Cities 6.6.0과 Imperial City 업데이트 6.6.0a 원본**을 먼저 설치합니다.
2. MO2에서 최종 한국어 ZIP을 별도 모드로 설치하고, 원본 설치 때 사용했던 도시 및 호환 패치 선택지와 같은 항목을 선택합니다.
3. 한국어 모드가 원본의 ESM/ESP를 덮어쓰도록 MO2 왼쪽에서 우선순위를 조정합니다. 플러그인 로드 순서는 원본 설정대로 유지합니다.
4. OBCJK와 한국어 글꼴 등 Oblivion Original의 UTF-8 한글 표시 환경이 필요합니다.

호환 플러그인 전부를 활성화하면 안 됩니다. 실제 원본에서 사용하는 플러그인만 번역 모드로 덮어씌우세요.
